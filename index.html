⚙️ First-Time Setup: GitHub + Replit – One-time only, skip if already done (click to expand)

Before you start, make sure you have:

  1. GitHub connected to Replit: Go to Replit → Settings → Connected Services → Connect GitHub
  2. A repo linked to your Repl: Either import from GitHub or create a new repo from your Repl

💡 Need help? See Replit's GitHub integration guide

📥 Installing Claude Code in Replit

Open the Shell tab in Replit and run:

🆕 NEW January 2025 Update: Native Installer

Anthropic now recommends the native installer over npm. It auto-updates, has no Node.js dependency, and avoids permission issues. The old npm command still works as a fallback.

⚠️ Run This EVERY Session to Start Claude Code

curl -fsSL https://claude.ai/install.sh | bash && source ~/.bashrc && claude
⚠️ Replit's shell resets between sessions – you must run this every time you start a new Replit session!
🔄 Native installer not working? Click for npm fallback
npm install -g @anthropic-ai/claude-code && claude
Note: npm won't auto-update – run npm update -g @anthropic-ai/claude-code periodically.
🆕 First-Time Setup: Create CLAUDE.md – Do this once per new project (click to expand)

⚠️ Do this once when starting a new project. This creates the CLAUDE.md file with all the safety rules built in.

📄 Copy This Into Claude

Create a CLAUDE.md file in the project root with this content: # Project: [Project Name] ## Rules for Claude (Always Follow) ### CLAUDE.md Management - Always read this file at the start of every session. - Update the Session Log at the end of every session with completed tasks and fixes. - If CLAUDE.md exceeds 30k characters, archive old session logs to CLAUDE_ARCHIVE.md before continuing. ### GitHub Safety - Always commit the current working code before starting edits. - If a change may break existing functionality, create a new branch and explain why. - Write clear, descriptive commit messages for all changes. ### Preserve Functionality - Do not remove or alter working features unless explicitly instructed. - If a change risks regression, stop and explain the impact before proceeding. ### Code Changes - Keep changes incremental and well-commented. - Highlight what was added, removed, or updated. ### Verification - After edits, run tests or basic checks to confirm nothing is broken. - Report any errors, warnings, or issues that appear. ### General - Treat GitHub as the single source of truth. - All steps must be safe, reversible, and transparent. --- ## Project Overview [Brief description of what this project does] ## Tech Stack - [List technologies, frameworks, dependencies] ## Project Structure [Key folders and files] --- ## Current Status - Status: [In Progress / Stable / Needs Review] - Last Session: [Date] - Current Branch: main ## Pending Tasks - [ ] [Task 1] - [ ] [Task 2] ## Known Issues - [None yet] --- ## Session Log ### [Date] - Initial Setup - Tasks Completed: - Created CLAUDE.md - [Other setup tasks] - Fixes Applied: - None - Notes: - Project initialized --- ## Project-Specific Rules [Add any coding conventions or requirements specific to this project]

📌 After Claude Creates the File: Commit It

git add CLAUDE.md git commit -m "docs: add CLAUDE.md with project rules and session tracking" git push

☀️ Morning Kick-Off Prompt

Use this at the start of every coding session.

🆕 NEW January 2025 Update: Auto-Archive for Large Files

We've added a file size check as Step 1! Large CLAUDE.md files (over 30-40k chars) can slow down Claude Code performance. The prompt now automatically archives old session logs to CLAUDE_ARCHIVE.md to keep things fast.

☀️ Start of Session

I'm starting a new coding session. Please: 1. Check CLAUDE.md file size - if over 30k chars, trim by moving old session logs to CLAUDE_ARCHIVE.md 2. Read CLAUDE.md for project context, rules, and pending tasks. 3. Run `git pull` to ensure we're up-to-date. 4. Run `git status` and `git log --oneline -5` to see recent activity. 5. Summarize where we left off and what's pending. 6. Suggest the best next step.

🌙 End-of-Day Wrap-Up Prompt

Use this at the end of every coding session.

🌙 End of Session

I'm finishing for the day. Please: 1. Confirm all changes are committed to GitHub. 2. If anything is in progress, save it on a separate branch. 3. Update CLAUDE.md: - Add today's date to Session Log - List tasks completed - List fixes applied - Add any notes for next session - Update Pending Tasks - Add any new Known Issues 4. Commit CLAUDE.md: "docs: update CLAUDE.md session log [date]" 5. Run `git push` 6. Confirm the project is in a safe state.

🔧 Troubleshooting – Common Issues & Fixes (click to expand)

❌ Claude Code not installing

Try: If native installer fails, use the npm fallback: npm install -g @anthropic-ai/claude-code && claude. If still failing, check your internet connection or restart the Repl.

❌ Git push failing

Try: Make sure GitHub is connected in Replit Settings → Connected Services. Also check you have write access to the repo.

❌ CLAUDE.md not being read

Try: Make sure the file is named exactly CLAUDE.md (case-sensitive) and is in the project root folder, not a subfolder.

❌ Claude forgetting rules mid-session

Try: Your CLAUDE.md might be too large. Use the Kick-Off prompt to check file size and archive old logs if needed.

❌ Changes not showing on GitHub

Try: Run git status to check for uncommitted changes, then git add ., git commit -m "message", and git push.
